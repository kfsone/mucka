	96 oo nn mm	Snoops from internal FE (oo*100+nn), snoop number mm,
			have ceased. Note that this code is immediately
			followed by its termination, as there is no data to
			bracket.

	97 oo nn	Snooped material from the player using internal FE
			(oo*100+nn). Note that this is not their snoop number
			(|1| or whatever), as such numbers wrap at more than
			10 snoops, and numbers are reassigned between snoops.
			The FE number remains the same until the player quits.

	98 nn		Snooped line prefix for snoop nn, where nn will be
			between 0 and 9 inclusive.

	99 ?? ??
	These are absolute colours, used in cases when something is
appropriate in a specific colour (eg. the greens & browns you get leaving
the Tearoom). The first number is 99 for absolute colour; the second
number is the foreground colour; the third number (if there is one) is the
background colour. Since there are a lot of combinations, I won't write them
all out - you can generate the rest automatically. Note that there are 8
background colours (including black) but there are 16 foreground colours, due
to the way that ANSI works.
